# Pixora

Локальное приложение для личной галереи на Android. Оно читает фотографии и скриншоты, которые уже лежат на телефоне, помогает вытащить из скриншотов полезный текст, найти лишние снимки и разложить кадры по альбомам.

Это не сервис и не облачная галерея. Регистрации нет, аккаунт не нужен, фотографии и распознанный текст никуда не отправляются. После установки приложение работает без интернета: в манифесте разрешение на сеть снято.

Сборка рассчитана на Samsung Galaxy S25 Ultra (`arm64-v8a`). На эмулятор с процессором x86 этот APK не встанет.

## Что умеет

Нижняя панель: **Главная**, **Скриншоты**, **Записи**, **Очистка**, **Альбомы**. Настройки открываются с главной.

### Главная

Счётчики берутся из локальной базы после чтения MediaStore, а не из демонстрационных данных:

- число фотографий и видео;
- число скриншотов и сколько из них ещё не разбирались;
- группы точных дубликатов и оценка места, которое можно освободить, после того как поиск уже запускали. До первого поиска стоит «не проверено», а не ноль.

### Скриншоты

Главный сценарий. Приложение находит скриншоты в стандартных и русских каталогах (`Screenshots`, `Скриншот`, `Снимок экрана` и похожие имена). Список можно сузить по периоду: всё, 7, 30, 90 дней или год.

Пакетный разбор:

1. Картинка декодируется через `ImageDecoder` с уменьшением длинной стороны до 2400 пикселей. В память не загружается вся галерея сразу.
2. Текст читает локальный Tesseract (`rus` + `eng`, быстрые модели в `assets/tessdata`).
3. Отдельный разбор текста пытается понять категорию и название. Название берётся только из распознанного текста. Если его нет в кадре, поле остаётся пустым или показывается как вариант, а не придумывается.
4. Результат кешируется по идентификатору файла, дате изменения и размеру. Неизменённый скриншот второй раз не распознаётся. Ручная правка при повторном прогоне не затирается.

Категории: фильм, сериал, дорама, аниме, рецепт, заметка, список покупок, ссылка, адрес, событие, документ, прочее. Подписи кнопок, ники и служебные строки TikTok и Instagram по возможности отбрасываются.

На экране проверки у каждой карточки видны исходный кадр, текст, категория, предполагаемое название, год и две оценки: уверенность OCR и уверенность правил. Категорию, название и год можно поправить. Есть флаги «сохранить информацию» и «удалить оригинал», пропуск и массовые действия.

Порядок удаления жёсткий:

1. Сначала данные записываются в локальную базу и проверяется, что запись читается.
2. Только после этого, и только для отмеченных файлов, вызывается системный запрос Android на перемещение в корзину.
3. Если сохранение не удалось, файлы в корзину не ставятся.
4. Удаление без сохранения требует отдельного подтверждения.
5. Пока система не подтвердила операцию, приложение не считает файл удалённым.

Безвозвратного удаления в обход корзины нет.

### Мои записи

Сохранённые карточки живут в Room и остаются после перезапуска. Их можно искать, фильтровать, править, помечать просмотренными, снабжать тегами и удалять. Исходный текст остаётся у записи.

Экспорт: TXT, Markdown, CSV, JSON. Импорт JSON сливает записи по ключу и не затирает чужие. Одинаковые названия с разным регистром, лишними пробелами и «ё»/«е» считаются одним и тем же.

### Очистка

- **Точные дубликаты.** Хеш SHA-256 считается только у файлов одинакового размера. В группе предлагается оставить избранное, иначе более крупный файл. Остальные сами не удаляются.
- **Похожие кадры.** Сравнение по dHash. Чтобы не перебирать всю библиотеку со всей библиотекой, пары ищутся внутри короткой серии и среди кадров одного размера. Какой снимок лучше, решает не размер файла, а резкость, экспозиция, разрешение и размер.
- **Рекомендации с причиной.** Точный дубликат, похожая группа, сильное размытие, старый скриншот, информация уже сохранена в записях. Избранное, защищённые альбомы и файлы из исключений не предлагаются к удалению.

«Ненужное» здесь только подсказка. Само по себе оно ничего не стирает.

### Альбомы

Умные альбомы не копируют файлы. Широкие категории (кошки, собаки, люди, еда и другие) ставятся метками ML Kit по миниатюре. Это общая категория, не опознавание конкретного животного.

Личный альбом, например «Мой кот», строится по нескольким образцам: сравниваются визуальный хеш и цветовая гистограмма. Результат — список похожих кандидатов с оценкой. Подтверждение добавляет образец, отказ запоминается. Гарантии, что это именно тот кот, приложение не даёт.

Физический альбом — это перенос через системный запрос на запись и обновление `RELATIVE_PATH` в `Pictures/Pixora/<имя>/`. Отдельная копия файла не создаётся. После индексации каталог виден в Samsung Gallery.

### Фон

Периодический разбор выключен, пока его не включат в настройках. Работает WorkManager: по умолчанию только на зарядке и не при низком заряде, не чаще чем позволяет система. Интервал 6–168 часов, по умолчанию 12. За один запуск обрабатывается ограниченное число файлов (по умолчанию 40). Непрерывного мгновенного сканирования Android не гарантирует, и приложение этого не обещает.

Пока приложение открыто, длинный разбор идёт в процессе. Если систему процесс завершит, прогресс на экране пропадёт, но уже записанный кеш сохранится, и следующий запуск пропустит готовые файлы.

## Настройки

- Тема: как в системе, светлая или тёмная. По умолчанию включены динамические цвета Material 3.
- Язык интерфейса: русский, английский или язык системы. Русский стоит по умолчанию.
- Фоновый разбор, зарядка, заряд батареи, интервал и лимит файлов.
- Порог похожести кадров (расстояние Хемминга 4–20, по умолчанию 10).
- Через сколько дней скриншот считается старым (по умолчанию 90).
- Исключённые альбомы и защищённые изображения.
- Экспорт и импорт базы записей.
- Очистка кеша анализа, сброс внутренних результатов и удаление записей разделены. Ни одно из этих действий не удаляет оригиналы в галерее.

## Разрешения

Запрашиваются только те, без которых функция не работает:

- чтение фото и видео;
- частичный доступ к выбранным фото на новых версиях Android;
- чтение внешнего хранилища только до Android 12;
- уведомления, если включён фоновый разбор.

Удаление и перенос идут через системные диалоги MediaStore. Root не используется.

## Сборка

Нужны JDK 21 и Android SDK с platform `android-37.1` и build-tools. Путь к SDK задаётся в `local.properties` (`sdk.dir`). Этот файл в git не входит.

```bat
gradlew.bat :app:assembleRelease
gradlew.bat :app:testDebugUnitTest
```

Готовый пакет:

`app/build/outputs/apk/release/app-release.apk`

Release сжат R8 и подписан отладочным ключом, чтобы APK можно было поставить без отдельного хранилища ключей. Обновление поверх сборки с другой подписью не установится. В пакет входят только библиотеки `arm64-v8a`.

Установка на подключённый телефон:

```bat
adb install -r app\build\outputs\apk\release\app-release.apk
```

Версия приложения: 1.0.0 (`versionCode` 1). `minSdk` 31, `targetSdk` 36, `compileSdk` 37.1. Идентификатор пакета: `com.pixora.gallery`.

Готовый файл также лежит в [релизе v1.0.0](https://github.com/TinVerner/pixora-app/releases/tag/v1.0.0).

## Как устроен код

Один модуль `:app`, без лишней многомодульности. Зависимости собираются вручную в `AppGraph`, без Hilt.

| Область | Где лежит |
| --- | --- |
| Галерея MediaStore | `data/media` |
| База Room | `data/db` |
| OCR | `ocr` |
| Смысл текста скриншота | `classification` |
| Записи и резервная копия | `notes`, `data/notes` |
| Точные и похожие дубликаты | `duplicates` |
| Рекомендации по очистке | `cleanup` |
| Альбомы и метки | `albums` |
| Пакетное сохранение и корзина | `ops` |
| Длинные задачи и WorkManager | `background` |
| Экраны | `ui` |

`ContentInterpreter` можно позже заменить локальной моделью. Сейчас смысл текста определяют правила, а не сеть и не большая нейросеть. Отдельная модель для «узнать моего кота» специально не встроена: визуальные кандидаты честнее, чем заявление об опознавании.

## Проверки

На JVM проходят тесты разбора текста, хешей, качества кадра, дубликатов, ключей записей и порядка «сначала сохранение, потом корзина».

На Galaxy S25 Ultra проверялись установка, чтение настоящей галереи, список скриншотов и пакетный OCR. Системная корзина и перенос в физический альбом на устройстве до конца не прогонялись: для этого нужно явное подтверждение, потому что операция трогает файлы.

Подробный статус, включая то, что ещё не проверено, лежит в `IMPLEMENTATION_STATUS.md`.

## Ограничения

- Качество OCR зависит от снимка. Текст кнопок и игрового интерфейса может попасть в название. Его нужно поправить или снять галочку сохранения.
- Похожие фото ищутся среди близких по времени и по размеру кадра, а не сравнением каждого файла с каждым.
- Метки ML Kit грубые. Личный альбом подбирает визуально похожие кадры и не обещает узнать конкретное животное.
- Фоновая задача подчиняется ограничениям Android и по умолчанию выключена.
